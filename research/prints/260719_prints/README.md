## 本批四組變更（詳 repo worklog 2026-07-19 §D–§I）

1. **wo5 盒**：出線口整併——兩個偏位槽補平，改為單一共用口 15×8 @ 牆正中（x−313, z c11.6，雙向置中），PAM2 喇叭線×2＋4P 電源線共走，經 Harry 打通的下方通道進 pivot window。J 鉤座未動。
2. **黃銅通道**：曲線通道（band_clamp 隧道、bce 抱孔、band_clamp 柱通道）**⌀4.3**；直線孔（pivot 軸承/柱端座、door_col 軌孔）**⌀3.8**。原因＝列印縮孔＋手彎曲率誤差（實測「剛好但塞不進」）。壓配全轉滑配，固定靠 M3。
3. **黃銅交界**：columns y+0.7 → 與 band 恰好相切（原 CAD 相疊 0.7mm，實體不可能）。彎線時兩管在夾座處應互貼、可焊。
4. **螺絲孔**：M3 牙孔 ⌀2.5→**⌀2.8**、過孔 ⌀3.2→**⌀3.4**（全件）；door_clip 雙孔距 **4→9.0mm**——**定案版＝夾片向板內加長 8mm（總長 43.5），孔在 x∓84.5＋∓75.5**（第一版向桶側外移會懸出門板、已作廢）→ 螺頭不再互疊、薄板不再被撐開、兩孔全落在門板上。
5. **門板（先 PLA 試印 → 驗證過才雷切）**：`door_panel.stl`（184×50×3 已轉平，直接切片）先印 PLA 對孔試裝；全對了再拿 `door_panel.dxf`（**mm 單位**，外框 184×50＋6×⌀3.4，3mm 楊木夾板）去雷切。孔與夾片牙孔同軸誤差實測 ≤0.023mm；鉸鏈側（A1/A2）孔在 X167.5/176.5、閂側（R）在 X7.5/16.5。DAEX 用黏的、不開孔（07-11 決議）。圖案不對稱但透孔板可翻面，切/印錯面翻過來即可。
