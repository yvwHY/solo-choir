## 一、WO-2 `band_clamp`：髮箍改成 C 口嵌入

**5627.4 → 6883.4 mm³**（含後面縮孔那步）

原本髮箍是「由上而下嵌進一條朝上的淺槽」——槽 6.0mm 寬、只有 3.2mm 深，髮箍 ⌀3 在裡面 Y 向可晃 3mm、底下還浮 0.7mm，而且比方塊頂面高出 0.25mm 露在外面。等於只是擱著，一晃就掉。

改成：

| 項目 | 值 |
|---|---|
| 補平原朝上淺槽、頂面上長 | z131 → **134**（+3mm） |
| 髮箍隧道 | **⌀3.1**，沿真實弧線（用 `Body70` 複製件面偏移 +0.05 當刀，不是近似曲線） |
| C 口 | **−Y 面（朝頭皮側）2.6mm 喉口**，全寬 x −17…+17 貫通 |
| 髮箍上方覆蓋 | 2.5mm 壁，完全不外露 |
| 圓角 | 後緣上長邊 R3／前緣上長邊 R0.5／C 口兩片唇各 R0.2 |
| 中柱通道 | ⌀4.3 重切穿新材料，後於縮孔步驟改為 ⌀3.1 |
| 中央 M3 ⌀2.8（z124） | 未動 |

**喉口為什麼只要 2.6（不做硬 snap）**：C 口朝頭皮，戴上時頭本身擋住出口，髮箍在 Z 向已被完全鎖死，只有水平往 −Y 才可能脫出。而 −Y 側壁只有 2.8mm 厚、唇很短，PLA 做太緊會裂。

**髮箍的實際位置**（pointContainment 掃描，供之後對位用）：z 幾乎不變 **130.0**，y 在 34mm 寬度內弧進 1.55mm（x0 → y135.90；x±17 → y134.35）；斷面 ⌀3 圓。

## 三、黃銅通道統一縮孔（黃銅實測 ⌀3.0）

260719 那批為了讓手彎黃銅穿得過去，把曲線通道開到 ⌀4.3、直孔開到 ⌀3.8，結果太鬆（約 1mm 餘空）。本次統一：

| 件 | 通道 | 改前 → 改後 |
|---|---|---|
| `door_col_A` / `door_col_R` | 直軌孔 | 3.8 → **3.2** |
| `pivot_mount` | 直孔 | 3.8 → **3.1** |
| `wo4_cup` / `wo4_cup_R` | 黃銅通孔 | 3.6 → **3.2** |
| `band_clamp` | 兩條中柱曲線通道 | 4.3 → **3.1** |
| `wo5_shell_v10` / `jhook_west` | J 鉤座 | 3.3 → **3.1** |

**驗證**：`measureMinimumDistance` 量到 `Body70`（髮箍）、`Body73`／`Body74`（兩中柱）到 `band_clamp` 的最小距離皆為 **0.0500 mm**（原為 0.6500），三條通道皆為精確 0.05mm 單邊餘隙、無干涉。`wo4_cup` 另以 ⌀3 桿全長探針驗證無阻、止付孔到底打通。

**J 鉤座（`wo5_jribbon_profile` → `Extrude348`）——最後是從草圖源頭改的**：

該座徑由草圖裡一條 **r=1.65 的弧**（curve[6]，圓心 (3.43,−63.87)，半圓）驅動。麻煩在於**這張 11 條曲線的草圖原本 0 個約束**——各曲線端點只是「數值上剛好重合」，所以：

- 單獨把弧半徑改成 1.55 → 弧端點跑掉、迴圈開口、`Extrude348` 直接失敗（Profile missing）
- 該面邊上的 **R1.0 不是圓角特徵做的**（沒有任何 fillet/chamfer 特徵擁有它，它是輪廓上的 curve[4] 弧），所以 UI 的 Press/Pull 也只會報「An existing fillet or chamfer could not be deleted」——**Harry 手拉同樣卡住**

**成功的步驟（照這個順序才會過）**：

1. `arc.radius = 1.55`——注意 Fusion 是**錨定起點、移動圓心**（圓心 3.43 → 3.33），不是兩端徑向外移
2. `arc.centerSketchPoint.move(+0.1, 0)` 把圓心平移回 3.43 → 端點成為 (1.88,−63.87)／(4.98,−63.87)
3. 相鄰兩線各移貼弧那一端 0.1mm：curve[7] 起點 → 1.88、curve[5] 終點 → 4.98（另一端不動，等於傾斜 0.65°，可忽略）
4. **加 3 個 coincident 約束**：curve[7].start↔arc.start、curve[5].end↔arc.end，以及最後**被前兩個約束拉出 0.0024mm 縫**的 curve[4].end↔curve[5].start

結果：profile 面積 143.68 → **144.97**，`Extrude348` 恢復健康，`wo5_shell_v10` **57270.2 → 57335.4**、`jhook_west` **6980.4 → 7045.6**，兩件的座都成為真正的 **⌀3.10 圓柱面**（面積 240.9，中心 y−76.87／z−3.43 未移動），唇口 R1.0 原封不動、開口維持敞開。

> 中途曾用「補一層 0.1mm 壁」繞過（只補 79°–281°），但那是**貼上去的東西、不是件本身**，Harry 否決，已完整退掉（4 個特徵）再走上面的正規路線。

## 教訓（今天真的踩到的）

1. **不要用 pointContainment 驗 0.05mm 級的餘隙**——邊界容差會讓「柱子」與「孔壁」同時回報 inside，我因此誤報了「199 點干涉」。這種尺度要用 `measureManager.measureMinimumDistance`，或用「拿刀再切一次、看移除體積是否為 0」。
2. **`addByThreePoints` 建的弧，起點可能是你以為的終點**。我用 `arc.endSketchPoint` 接線，接成兩條對角線 → 封閉輪廓變 X 形蝴蝶結，只切開中段；端面看起來仍是 O 不是 C。**輪廓建完一定要印 profile 面積跟幾何算的比對**（正確值 222.5 vs 幾何 221.5）。
3. **只驗一個剖面等於沒驗**。上面那個 bug 我在 x=0 探到「通了」就宣稱完成，兩端根本沒開——是 Harry 看端面抓到的。
4. **補丁補不動就整件重建**。WO-3 我走了「縫合→補孔→削耳→削過頭→退回」的遠路；重建反而快又乾淨。
5. **削凸台不能對著錯的軸切**。第一次拿軌孔軸當切削圓柱的軸，把 ⌀12 筒身沿全長刮掉一條 0.28mm 月牙（⌀12 是 door_clip 抱的面）。要用**筒身自己的軸**，而且切削圓柱的長度要從件的實際軸向範圍算，別用 bbox 角點投影（會高估）。
6. **改動舊草圖會觸發全時間軸重算**（本檔 ~790 特徵，每次 3–5 分鐘），而且**重算會把 base feature body 的改名還原**（`door_col_A` 變回 `door_col_A_NEW`），改完要檢查。
7. **無約束草圖靠「數值重合」成 profile**，改任何一點都會開口，而且**浮點誤差 1e-3 mm 級就足以讓 profile 消失**。修法是移完點之後補 coincident 約束把端點釘死；補約束時**約束求解器會把相鄰線拉斜、在別處拉出新的縫**（本次是 0.0024mm），所以要逐一掃「沒有配對的端點」直到 profiles 回到 1。
8. **貼上去的補丁不算解**。J 鉤座一度用 0.1mm 補壁繞過，形狀對、數字對，但那是額外貼上去的東西——Harry 一眼看出來並否決。能從參數／草圖源頭改就別用布林補。
