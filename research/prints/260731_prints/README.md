# 260731_prints — 一件式方錐 voice unit（v7 終版）

來源：Fusion `solo_choir_frame_a`（body: `vu2_pyramid`）。
設計脈絡：HARDWARE_ROADMAP §4a（2026-07-31 晚,七迭代收斂:bayonet → 深窩 → 配重杯 → 一體裙擺 → 方錐 → 去杯一件式 → **純梯形錐體(Harry 定案)**）。

## 設計一句話

**一站＝一個列印件**:**純梯形錐體**:底 65×65 直斜到口 104×104(h90,無柱段,側視=梯形;內部 61×61:35/50mm 驅動器皆可平放,僅 65mm 大顆 DAEX 放不下(原圓 cone 裡它也只是勉強,捨)),壁 2.0、底 2.0(exciter 平台,⌀25/35/50 定位環)、側壁出線孔 ⌀12@z14。**固定=黏,不配重**(桌子就是配重;沙倉/杯/卡口/silicone 全部退役):立放=底面 VHB 貼桌;躺放=任一稜面平貼桌面(方錐不滾),還可刻意面貼桌把桌面當共鳴板(07-31 實測「貼桌很大聲」的可控版)。零組裝、零配合公差。

## 組裝(一件式,只有三步)

1. **exciter 上樓面**(07-28 貼法紀律):磨平(220→400)＋IPA → 薄 PET 雙面膠、對定位環。**A/B 拍板前不上環氧。**
2. 線從側孔(⌀12@z14)出,JST 頭直接過。
3. 擺位:立放=底面 VHB 3-4 片;躺放=稜面貼桌＋博物館泥(要桌面共鳴就壓緊、要乾淨聲就墊 silicone 條隔開——兩種耦合都試,耳朵裁)。

## 驗收閘門(過了才印四件)

- [ ] 同訊號 A/B:vu2_pyramid vs 現任 vu2_cone(圓 vs 方=平面振動特性差異,耳測裁)
- [ ] 立放/躺放各聽一輪;躺放試「壓緊桌面」vs「silicone 隔開」兩種耦合
- [ ] 無晃動碰撞聲(有=VHB/泥沒貼實)

## 驅動器配置(零採購)

Dioche 50mm ×2 → 低聲部、FAUOSWUK 35mm ×2 → 高聲部(震動大→樓面加配重墊圈)。型號差用 UI per-voice trim 配平。
