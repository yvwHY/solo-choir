# 260801 mesh coupon — 網布×剛性板漸變實驗片

穿戴新方向（3D 列印網狀布料＋exciter 剛性板）的打樣。驗證「板→網漸變」的圖案語言＋板區貼 exciter 的聲學表現。**實驗件，不是定案設計。**

**方向拍板（Harry 2026-08-01）：auxetic structure**（拉脹結構——參考圖那種「密區近實面、張力下展開成蕾絲」的語言）→ 主打樣 = v2。

## 實測（260803，PLA、MINI IS）
- **v2 印出來拉不開，太硬。** gcode 分析排除了 slicer 填縫（`Gap fill` 零行、613 段 external perimeter＝縫確實被當孔洞繞了輪廓），所以不是切片問題。剩兩個候選：①0.6 縫物理黏死（擠出膨脹＋塌陷）②**rotating squares 是單自由度機構，中央 ⌀55 實心板把全域旋轉角 θ 鎖成 0 → 整片鎖死**。鑑別測試＝從角落剪 40×40 純網區單獨拉：拉得開＝②，拉不開＝①。**未執行，根因待定，因此尚未登記 GRAVEYARD。**
- **v3 印出來可以拉開，但只有「微微」，且越往內越硬。** 內外差異＝桿寬漸變（設計意圖）＋中央板本身是剛體；但整體偏硬是另一回事 → v5。

## 無板對照組（260803）
中央 ⌀55 實心板同時是「v2 鎖死」和「v3 越向內越硬」的嫌疑犯之一。拿掉它 → 純網基準線。
- **只改一個變數**：移除板，**桿寬徑向漸變刻意保留**（`rib_w()` 仍以 R_PLATE 為漸變起點，中央區桿寬 2.0）。所以中央仍是「硬網」但不再是絕對剛體 —— 差異才可歸因
- `gcode/coupon_v3_noplate.gcode` — **9.79 g／1h03m**（厚 0.8）
- `gcode/coupon_v5_noplate.gcode` — **6.20 g／33m32s**（厚 0.6）
- 讀法：**有板 vs 無板同版本對拉**。若無板版明顯好拉 ⇒ 板是主因，最終件的板必須跟網解耦（浮動接合／過渡帶），不能直接 union 成一體；若差不多 ⇒ 板無罪，問題純粹在桿的剛度，繼續往 v5 的旋鈕走

## v5 幾何（v3 軟化版，260803）
剛度公式：**桿件面內彎曲剛度 ∝ t·w³/l³**（t 片厚、w 桿寬、l 桿長）。v3 只動了 w，而 w 的下限是 0.8＝2 走線（再降就掉回 v2 的窄縫坑）。**l 同樣是三次方項，而且沒有地板——那是 v3 漏掉的旋鈕；t 從 v1/v2 沿用 0.8 也從沒重新想過**（v2 是切縫片需要面外剛度，v3 是桿件網不需要）。
- **格子等比放大 1.5×**：W 12→18、HV 9→13.5、S −3.5→−5.25（排距 8.25），內凹角維持 30.3°
- **片厚 0.8→0.6**（3 層）
- 桿寬維持 2.0→0.8（漸變比例不動——內外差異是設計意圖，這次修的是整體剛度）
- **預估整片剛度 ×0.23**（桿長 ×0.296、片厚 ×0.75、並聯列數 12.5→8.3 使整片 ×0.67、串聯排數 25→16 使整片 ×1.56）⇒ 同樣拉力下位移約 4.3×。**這是估算，不是實測**
- **gcode：`gcode/coupon_v5_soft.gcode` — 10.24 g／39m42s**（brim 5，同 v3）
- 還嫌硬的話，下一個旋鈕依序是：片厚 0.4（×0.5，但 2 層細桿首層容易被拖走）→ 格子再放大到 1.75×（×0.62）→ TPU。**TPU 在 MINI IS 上不是換料就好**：Bowden 擠出機要用 95A、速度砍到 15–20 mm/s，這片會從 40 分鐘變 3–4 小時，且軟料易堵管

## v4 幾何（交錯直縫 kirigami，260803）
保住 v2 的語言（印時近實面、張力下浮現蕾絲），但把縫的拓撲換掉：**一排排長直縫、奇偶行錯開半週期**，縫數從 650 降到 ~160。縫因此可以放寬到 **0.8（＝2 走線，0.4 噴嘴必定留空）**，而開孔率反而從 v2 的 ~11% 降到 **7.4%＝比 v2 更像實面**。
- 縫週期 20.0、行距 8.0（＝條帶寬）、縫寬 0.8、18 行
- **漸變＝橋接段長度**：板附近 6.0（硬、幾乎不開）→ r70 外 2.0（軟、先開）。**縫週期固定、縫長隨半徑變 ⇒ 縫中心不動**，漸變不會扭曲圖案（這是 v3 桿寬漸變的同一招：只動不移動節點的參數）
- 縫端用 **round cap＝洩壓孔**。v2 是 flat cap，縫端是直角＝鉸鏈根部的應力集中點，PLA 會從那裡先裂
- 左右邊緣的縫被裁斷成開口，是預期的——外緣本來就該先開
- 中央板 ⌀55、厚 1.6：同 v2

### v4 列印與風險
- **gcode 已切：`gcode/coupon_v4_kirigami.gcode` — 23.03 g／1h26m**（同 v2 的 `miniis_grid.ini`，近實面不需要 brim）
- 對 v2 只快 27%，不是砍半——縫的周長少了，但開孔率更低＝實心填充更多，兩者互相抵消。**v4 的賣點是零黏死風險＋更像實面，不是速度**
- **未驗的風險（預測，非實測）**：展開後期靠 0.8 mm 條帶面外挫曲，那個曲率尺度下的應變恐怕超過 PLA 的斷裂應變。小幅面內張開安全、大幅展開可能裂。這個 pattern 真正的家是 TPU；PLA 版當形態驗證

### v4 印後驗收
1. 0.8 縫有沒有印通（這版若還黏死，就是機器問題不是設計問題）
2. **先小幅拉**：外緣先開、往內漸層、板區不動
3. 再逐步加大到條帶翹起（面外）——記錄裂之前能開到多大，這個數字決定 PLA 夠不夠用
4. 對照 v3：同樣拉伸下誰先壞、誰的漸變更看得出來

## v3 幾何（re-entrant honeycomb，260803）
換家族的理由＝**列印方便性**：切縫式（v2）的機構本身就是窄縫，0.6 縫配 0.4 噴嘴是邊界值、零餘裕，且 650 條短縫＝~8 m 內壁周長。桿件式把機構改成桿件彎折，負空間全是 mm 級 → 無 gap-fill／黏死風險，且**印出來就是展開態**，直接繞過 v2 記的「預轉開會焊死」課題。
- cell 12.0 × 5.5：垂直桿長 9.0、斜桿垂直位移 −3.5（負＝內凹），內凹角 30.3°，25 排
- **漸變＝桿寬**：板附近 2.0（硬）→ r70 外 0.8（軟）。面內彎曲剛度 ∝ 桿寬³ → 軟硬差約 15×
- **為什麼不是內凹角漸變**：內凹角會改變排距（ROW_H = HV + S），節點位置跟著動 → 笛卡兒晶格無法做徑向漸變（只能沿 y 做帶狀漸變）。要真正的徑向內凹角漸變得改極座標（同心環）晶格，屬後續課題。桿寬漸變的節點固定，是這裡唯一乾淨的解。
- 負泊松比方向：沿 y 拉 → 斜桿轉平、|S| 減小，桿長固定 ⇒ W 必須增大 ⇒ **橫向同時變寬**
- **上下 3 mm 夾持條、左右刻意開放**——橫向膨脹才目測得出來（有外框就看不到了）。左右邊緣會有被切斷的半根斜桿毛刺，是預期的，不影響列印
- 中央板 ⌀55、厚 1.6：同 v2

### v3 印後驗收
1. 細桿有沒有斷線／缺料：外緣 0.8 mm 桿＝2 條走線，斷續代表這台的最小桿寬要往上調（改 `RIB_FAR`）
2. 首層有沒有被撞掉：brim 5 夠不夠，不夠就加到 8
3. 負泊松比：抓上下夾持條往外拉 → **左右邊界應該同時往外變寬**（不是縮腰）。看得到＝機構成立
4. 漸變：拉的時候外緣先開、板區幾乎不動
5. exciter 膠帶暫貼板區 → 耳測：桿件網對板的阻尼 vs v2 切縫片 vs 裸板

## v2 幾何（auxetic 切縫片）
- 印時＝近實面：8 mm 方塊格、縫寬 0.6、片厚 0.8（4 層）；**拉開時方塊繞角鉸旋轉、蕾絲感在張力下浮現**（rotating-squares 機構，負泊松比：拉長時橫向也變寬）
- 漸變＝**鉸鏈長度**：板附近 2.4 mm（硬、幾乎不開）→ r70 外 0.8 mm（軟、先開）——拉伸時開放度由外往內漸層出現
- 中央板 ⌀55、厚 1.6：35 mm exciter＋468MP 有餘裕，貼面朝上
- 注意：曾試過「預轉開」版本（印成已展開狀態）——固定格距下角落互相重疊焊死，**預轉開需要格距跟著變大**，v2 用閉合態迴避；要「印出來就是開的」的區域屬 v3 課題

## 幾何
- 三角網格：三方向格線間距 8 mm，桿寬 1.4 mm（板附近）→ 0.8 mm（外緣）漸變
- 中央板 ⌀55、厚 1.6（8 層）：35 mm exciter＋3M 468MP 膠圈有餘裕，貼面朝上（光滑）

## 印後驗收（v2）
1. 縫有沒有印通：0.6 mm 縫不得黏死（黏死＝這台機器的縫寬配方要加大，改 `SLIT_W` 重生）
2. 拉開行為：雙手拉外緣 → 外緣先開、往內漸層、板區不動；方塊是「旋轉」不是桿件彎折
3. PLA 鉸鏈耐受：反覆開合十次外緣鉸（0.8×0.8 mm）不斷——斷了表示 PLA 只能當形態驗證，垂墜/常穿版要 TPU
4. exciter 膠帶暫貼板區 → 耳測：網對板的阻尼是幫忙還是扣分（對照裸板/夾持）
5. 過了 → v3 課題：預轉開區域（格距漸變）、TPU 對照、照打版版型換外輪廓
