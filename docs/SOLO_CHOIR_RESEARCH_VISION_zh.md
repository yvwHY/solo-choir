# Solo Choir — 研究願景與統一 Roadmap

*一個用來「**學習**」與「**延伸**」歌唱身體的穿戴式樂器。*
*一稿三用:(1) viva 論述骨架 · (2) HARDWARE_ROADMAP 的後繼框架 · (3) PhD / MIT Media Lab statement 的底稿。Living document — 最後整理 2026-06-23。*

---

## 1. 一句話主張

**身體作為和聲的介面。** 一個歌者成為自己的合唱團——而這個合唱是**在身體裡學會**、**從身體裡演出**,不透過螢幕或喇叭中介。

同一個概念的兩種模式:
- **體內學習(Learn in-body)**:用骨傳導(開放耳)把一條**獨立的和聲目標**送進腦袋,你同時聽到自己的聲音**和**目標,靠體感訓練音程。
- **從身體演出(Perform from-body)**:所有和聲聲部**同時**從一個身體發出,**超越人聲「一次只能一個音」的極限**。

## 2. 研究問題

> *把和聲送「**進 / 從身體**」,會不會改變歌者**學習**與**演出**和聲的方式——相較於螢幕或喇叭中介的和聲?*

這是脊椎。下面兩條 track 都是為了回答它;兩者都不是獨立的 demo。

## 3. 為什麼這是貢獻(而不只是一個人聲效果)

- **同時性 = 字面意義的身體延伸。** 人聲是單音的——一次一個音高。Solo Choir 讓一個身體成為**同時**的 SATB 和弦。這就是「choir of one」:不是效果,是**沒輔助的身體做不到的能力**。*(「超越人聲一次一音的極限——身體成為一個同時的和弦。」)*
- **開放耳骨傳導是有教學動機的,不是裝飾。** 要唱準,歌者**必須聽到自己的真實聲音**;封閉式耳機會把它蓋掉(occlusion effect——這就是為什麼錄音室歌手會把一邊耳罩拿下)。骨傳導給你**目標**、又不擋住**聽自己** → 這讓骨傳導成為一個**可被否證的主張**,不是噱頭(見 §6)。
- **Real-time on CPU + live/render 取捨**本身就是一個誠實、值得寫的工程 framing,不是要藏起來的限制(§7)。

## 4. 兩條 track(都做,且統一)

### Track A — 軟體:和聲視唱訓練器 *(承載研究可信度)*
- 建在現有引擎上:**record → SATB 分軌**已經有了;加上 **solo / mute(+ loop)** 播放,讓學習者能單獨抽出一個聲部。
- **跟唱時用引擎現有的 `f0 / midi / cents` telemetry 做音準回饋** → 「目標 A4,你偏低 30 cents」。這把「練習帶」升級成**有回饋的**視唱訓練器,而且**重用現成的東西**。
- **錄下來的 stem 是凍結的、獨立的目標** → 解掉了 live 即時和聲「只會影子你、沒東西可學」的循環問題,**而且學習用途不需要 MIDI**。
- 兩個練習子模式:**唱你該唱的目標聲部**(較易) vs **頂住別的聲部**(真正的合唱能力)。

### Track B — 硬體:具身傳遞 *(承載新穎 artifact)*
- **學習模式 = 骨傳導、開放耳。** 獨立目標進腦;自己的聲音仍聽得到。(學習要的是**音高**準度;骨傳導對歌唱 f0 範圍沒問題,音色悶無妨。)
- **表演模式 = 對外輻射(DAEX 嘴罩)。** 合唱實體**從歌者自己的嘴/身體發出**,跟真聲在同一空間混合 → 整個合唱讀起來像從一個人身上長出來。
  - **正式更正:** DAEX-嘴罩是**具身 / 空間聲源**裝置,**不是** formant filter。真正的嘴部 formant 塑形需要 talkbox 把管子伸**進嘴裡**,而軟體(Beatrice)已經可控地掌握音色——所以音色仍是軟體的工作。嘴罩要測的是*「讀不讀得出從我身上發出 / 跟真聲融合」*,不是測音色變化。
- 在身體上,**「You」關閉**(真實人聲就是 unison) → inference pass 變少 → 為**加上去的**和聲留出更多即時餘裕。

## 5. 這不是什麼(scope 紀律)

- **不是** viva 前換引擎(RAVE / DDSP / ACE-Step:沒有 pitch 控制、要 GPU + 數週訓練,而我們在 CPU/Mac)。
- **不是** 追自訓模型品質(25 分鐘 / 10k steps 結構上太少——把它當一個 finding 寫下來)。
- **不是**「身體當 formant filter」的主張(已收回——見 §4 Track B)。
- 對 Media Lab/PhD,**連貫性 > 功能數**:每條 track 把它**最核心的一件事**做到極好,而不是兩個各做一半。

## 6. 評估(這才是讓它成為「研究」的部分)

依指導教授建議(Yee-King,2026-06-23)——現在是核心,不是 polish:

1. **學習比較研究:** *骨傳導(開放耳) vs 封閉耳機 vs 房間喇叭*——哪一種讓歌者**最快、最準**學會 / 守住一個和聲聲部?用引擎的 `cents` 誤差與守住音高的時間量化。
2. **合成品質 baseline 階梯:** ① 純 pitch-shift(+EQ) vocoder baseline → ② Beatrice →(可選 ③ 用 Neutone 載 pre-trained RAVE/DDSP)。用 render pipeline 產乾淨 A/B(/C) clip;說明 baseline **為什麼不夠好**。
3. **聽測指標:** *像不像不同的人 · 假不假 · 準不準。*

## 7. 誠實的技術 framing — live vs render

- 每個轉換聲部 = +1 inference pass;CPU 上 **live ≈ ≤ 3 部**,**完整同時 SATB = offline render**。這就是 Record→Play / render 存在的原因。
- 穿戴模式救回一些:**on-body 關掉「You」** → 只跑和聲那幾 pass。
- 別過度宣稱「即時完整 SATB」。live/render 的落差是**這個樂器的合理 framing**,也是值得記錄的真實工程貢獻。

## 9. 未來工作 = PhD 願景

- **生物訊號 / EMG 驅動的和聲**——讓**身體指揮**合唱(喉部 EMG、呼吸、下顎),取代固定 diatonic 音程或 MIDI 和弦。(先例:*Singing Knit*;歌手的 EMG 生物回饋。)
- **穩健的骨傳導 / 口內**具身傳遞;完整 wearable 形體(proposal 裡的醫療支架 / Rebecca Horn 美學)。
- 身體上的多聲部、同時、即時。
