## 面罩 CAD — 從手稿到 `mask_concept11`（Track B）

一整天的 Fusion 馬拉松：把 Harry 的手繪側視概念圖（`260702/Mask_side.jpg`）
變成一顆可戴、可印的實體，經 11 個版本迭代（concept4 → 11，中間版本各修一個
結構性 bug）。最終建法是一條**全腳本化的重建鏈**，任何外形修改都重跑鏈即可：

1. **A＝側面剪影擠出**：OpenCV 抽手稿外輪廓（細筆觸 → dilate 封縫 → floodfill
   填滿 → 70–90 點輪廓），經 canvas Matrix2D 對位進世界座標，yZ 草圖對稱擠出。
2. **∩ 蛋形包絡**：正面手稿（`Mask_front.jpg`，XZ canvas）抽每高度半寬 w(z)，
   逐層**超橢圓**（n=3.5，頂部漸變到 2.0）loft — 俯視/正面都是蛋形，且 visor
   前端保留 ~65% 寬度包住臉頰（純橢圓會變鳥嘴、側面露臉，已踩過）。
3. **− 頭腔**：頭 +8mm（頭頂圓頂 +4mm）的平滑剖面 loft，佩戴空隙。
4. **− 三個 empty space 空腔**：手稿內部輪廓分區（floodfill 區域、質心配對、
   縮邊留 ≥5mm 壁）→ 內藏腔（頂帶/太陽穴/嘴前音箱條）。
5. **− 元件座**：DAEX ⌀49×20 圓袋（嘴前 z=52）；BCE-1 骨傳導 18×22mm
   **穿透窗**於顳骨（±x, y=32, z=130）— 盲槽貼不到皮膚，開窗由鬆緊帶壓緊。
