## 硬體選型 research（嘴前發聲器＋amp）

- Harry 實測：**DAEX 不需要腔體也能發聲** → 杯可去腔段瘦身。
- **DAEX-9-4SM（9mm）不能當人聲主發聲**：Fs 1200Hz，基頻 130–500Hz 段
  滾降 20–30dB，聽感＝電話（missing fundamental 保住音高與可懂度，失去
  胸腔感）。定位改為**觸覺層**（下巴叉/帶內側，跟 haptic 計畫接軌）。
- **甜蜜點：Tectonic TEAX19C01-8**（Fs 350Hz、2W/峰4W、8Ω）——RS UK 下架，
  SoundImports 有貨。**購買 gate：先實秤 25CT-4**（標稱 74.6g 疑含包裝，
  coin type 實體可能僅 ~30g；若輕則不必換）。
- **BCE-1 的物理極限**：Fs 2100Hz（顳骨自監聽偏薄是元件不是調音）。加層
  選項：**BCT-2**（10W、Fs 530Hz）貼胸骨＝「空氣＋顱骨＋胸腔」三層身體聲場。
- **Amp**：現行系統 PAM8406（5V USB 內、L=BCE-1×2 串聯 8Ω、R=嘴前）；
  若上 BCT-2 → TPA3116 2.1 板（sub 聲道餵胸骨）或 Wondom JAB（鋰電一體）。
- Amazon 推薦頁掃雷：藍牙骨傳導喇叭（延遲）、Hi-Low converter、M6 螺絲、
  微型錐盆喇叭全數跳過；£9 的 35mm resonance speaker 可當實驗品。
