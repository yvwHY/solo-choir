## B. Live multi-voice investigation — the hard real-time limit (accepted)
Symptom: **live**, adding any female voice (Alto/Sop) → **滋滋波波** crackle; all-tenor
multi-pass (You+Bass+Tenor) **clean**; **offline always clean**.

Investigation (this is the honest, useful part for the viva):
- **Benchmark** (`/tmp/bench_parallel.py`): `process_frame` ≈ **1.3 ms/pass**; 3 passes ≈ **4 ms**
  vs the **10 ms** callback deadline → compute has huge headroom. **GIL is NOT released**
  (parallel speedup 0.97×) → can't fix by threading the passes.
- So the crackle is **jitter**, not compute. Tried `gc.disable()` (callback churns numpy arrays →
  GC pauses) — **no help** → not GC either.
- Narrowed it: noise is specific to a **2nd model** loaded alongside the tenor. (Even "You+Sop"
  runs 2 models — voice 0 = Bass-tenor always runs as the pitch/timing reference.) Hypothesis:
  **two model weight sets thrash the CPU cache** between the 10 ms callbacks; offline / the warm
  benchmark keep them hot, so they don't reproduce it.
- **Test of the hypothesis:** trained the `satb2` 2-speaker model so all parts share ONE weight
  set → **still 滋滋波波 at 2 passes + Sop warbles live.** So "one model" did **not** fix it →
  the cache-thrash story is incomplete; **live multi-timbre / female-pitched-up is just a hard
  real-time limit on this laptop.**
- Also surfaced: `input overflow` from a **device-clock mismatch** (USB mic + built-in speaker =
  two clocks) — needs a macOS **Aggregate Device** (in+out, drift correction). Built-in speaker
  out also risks feedback; use headphones.

**Resolution (`cf079710`):** live reverted to **`satb=False`** — the proven, byte-identical
single-voice path (You + one harmony), which the singer confirmed clean. The female + `satb2`
models stay wired (`model="female"` / `"satb2"`) for the **OFFLINE render**, which is clean and
is the demo deliverable. This is exactly `MULTIVOICE_STATUS.md` §3/§5/§7's documented split,
now empirically nailed down: **live = single-voice; full male+female SATB = offline render.**
