## B. 「瓦斯洩漏」嘶聲 → ground loop 確診（非 AI-Micro、非 PAM8403 本身的鍋）
- 症狀：無播放時持續寬頻嘶聲；拔輸入線消失；音量 0 不變；Mac 孔和 AI-Micro 都一樣。
- 隔離鏈：拔 AI-Micro→amp 線 → 嘶聲消失（排除 amp 自噪）；換 Mac 孔做音源 → 嘶聲仍在（排除 AI-Micro）；**amp 供電從「Pico→hub→Mac」改到延長線 USB 口 → 嘶聲消失 = 確診 ground loop**（環 = Mac USB 電 → PAM8403 → 音訊地 → 回 Mac；與 07-07 量到的「地走兩條路」同類）。
- **正式版免疫 by design**：WO-5 電池懸浮軌（5V 永不走 USB）本來就斷環，不用買隔離器、不用 L-pad。bench 期臨時規則：**amp 的電永遠不要跟音源共用同一台電腦**。
- 過程中一度誤診為增益結構/DAC 底噪問題（L-pad 方案）——保留備忘：若日後換高靈敏度換能器仍聞底噪，L-pad（1kΩ＋100Ω ≈ −21dB）是正解，但今天的嘶聲不是這個成因。

## C. BTL 短路教訓（NEW 安全規則）
- 量延遲時 BCE 背面裸焊點直接壓上喉麥金屬殼 → **PAM8403 秒速發燙**。成因：PAM8403 是 BTL 橋接輸出，喇叭任一端子碰地＝短路；喉麥殼經 AI-Micro 接地。斷電冷卻後正常（有過熱保護），加一層膠帶絕緣後量測順利完成。
- **形式規則（進骨架前必做）：BCE 焊點/裸線必須全部熱縮或點膠封死**——⌀3 黃銅骨架滿頭都是接地路徑等效的金屬，裸焊點靠上去就是 §C 重演。與 07-12 §B 既有待辦「焊盤裸線防互碰」合併升級為硬規則。
