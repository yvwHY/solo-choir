## B. WO-2 `band_clamp` — 髮箍改 C 口嵌入（5627.4 → 6869.6 mm³）

原況：髮箍（⌀3 黃銅弧 `Body70`）擱在一條**朝上、6.0mm 寬、僅 3.2mm 深**的淺槽裡 → Y 向可晃 3mm、底下浮 0.7mm、頂面還高出方塊 0.25mm 露在外。

改成：補平原槽 → 頂面 z131→**134**（+3mm）→ 沿真實弧線切 **⌀3.1 隧道**（用 `Body70` 複製件面偏移 +0.05 當刀）→ **−Y 面（朝頭皮側）開 2.6mm 喉口、全寬 x−17…+17 貫通** → 圓角後緣 R3／前緣 R0.5／C 口兩唇 R0.2。髮箍上方留 2.5mm 壁，不外露。

喉口不做硬 snap 的理由：C 口朝頭皮，戴上時頭本身擋住出口，Z 向已被鎖死；而 −Y 側壁僅 2.8mm、唇短，PLA 做太緊會裂。

**髮箍在此段的實測位置**（pointContainment 掃描，供日後對位）：z 幾乎不變 **130.0**，y 在 34mm 寬度內弧進 1.55mm（x0→135.90；x±17→134.35）。

## C. WO-3 `door_col_A/R` — 整件重建（A 2905.7→3100.3、R 1503.2→1569.1 mm³）

原況＝**開縫抱箍**：全長 1.2mm 的縫從軌孔開到外表面，兩端各一個帶 M3 的耳朵（⌀3.4 過孔＋⌀2.8 牙孔沿 X），鎖緊夾攏擠壓軌孔。PLA 薄件不是夾不牢就是撐裂。

先走「就地補丁」（縫合→補孔→削耳），**削耳時把 ⌀12 筒身也刮掉一條 0.28mm 月牙**（切削圓柱對到軌孔軸，但筒身軸與軌孔軸偏心 0.20–0.26mm 且不平行 0.14°）→ 退回 → Harry 裁決改整件重建。

重建規格（原位置、原軸向；A 筒軸點 (−110,−22.937,−99.880)、R (110,−25.031,−103.036)，方向皆 (0,−0.498496,−0.866892)）：

- **A**：⌀12 [−28.70,−22.15]／**⌀8 [−22.15,−17.25]**／⌀12 [−17.25,−4.90]／**⌀8 [−4.90,0]**／⌀12 [0,+7.30]，端面兩圈 R0.8
- **R**：⌀12 [−12.50,−5.95]／**⌀8 [−5.95,−1.05]**／⌀12 [−1.05,+6.00]，槽的兩個 ⌀12 邊 R0.8
- 兩道 ⌀8 卡槽寬皆 **4.90**、位置與原件**逐段 0.25mm 取樣比對相同** → `door_clip` 不必改
- 軌孔改為**與筒身同心**（原件偏心 0.2mm、不平行 0.14°，舊模型殘留）
- **⌀2.8 止付牙孔各兩顆**，站位沿用原夾片（A s=+4.266／−25.750；R s=+3.011／−9.524），**A 從 −X、R 從 +X**（皆朝外），牙深 (12−3.8)/2 = **4.1mm**

## D. 黃銅通道統一縮孔（黃銅實測 ⌀3.0，Harry 定數）

| 件 | 通道 | 改前→改後 | 餘隙（單邊） |
|---|---|---|---|
| `door_col_A/R` | 直軌孔 | 3.8 → **3.2** | 0.10 |
| `pivot_mount` | 直孔 | 3.8 → **3.1** | 0.05 |
| `wo4_cup`/`_R` | 黃銅通孔 | 3.6 → **3.2** | 0.10 |
| `band_clamp` | 兩條中柱曲線通道 | 4.3 → **3.1** | 0.05 |
| `wo5_shell_v10`/`jhook_west` | J 鉤座 | 3.3 → **3.1** | 0.05 |

**驗證**：`measureManager.measureMinimumDistance` 量到 `Body70`／`Body73`／`Body74` 到 `band_clamp` 皆 **0.0500 mm**（原 0.6500）。`wo4_cup` 另以 ⌀3 桿全長環狀探針驗證無阻、止付孔到底打通。

**中柱道敢縮到 3.1 的理由**（Harry 定）：band_clamp 那兩條只有 17mm 長，手彎曲率誤差在這麼短的距離內累積很小——與 260719 卡死的長通道情況不同。

**J 鉤座是特例**：⌀3.3 由 `wo5_jribbon_profile` 一條 r=1.65 的弧驅動，而該草圖**原本 0 個約束**（端點只是數值重合），單改半徑會讓輪廓開口、`Extrude348` 失敗；該面邊上的 R1.0 **不是圓角特徵**（是輪廓上的 curve[4]），所以 UI 的 Press/Pull 也報「fillet could not be deleted」——Harry 手拉同樣卡住。正解四步：①`arc.radius=1.55`（Fusion 是錨定起點、移動圓心）②圓心平移回原位 ③相鄰兩線各移貼弧端 0.1mm ④補 **3 個** coincident（第三個是補前兩個時被求解器拉出的 0.0024mm 縫）。中途曾用「補 0.1mm 壁」的布林繞過，Harry 一眼看出是貼上去的東西並否決，已完整退掉 4 個特徵。

## F. 列印前才抓到的三個幾何瑕疵（都已修）

1. **`band_clamp` z 高 21mm 而非 20mm** — 填中柱道時柱塞裁到的盒子比方塊上下各多 0.5mm，留下兩截凸出的 ⌀4.3 環。裁回 z114–134（−13.8 mm³）。**是對 STL bbox 才發現的，Fusion 內不會叫。**
2. **P1 盤只有一個 J 鉤** — Harry 在 gcode 預覽抓到。`jhook_west` 被我依「bbox 落在殼的範圍內」誤判為工作 body，實際上殼 body 內是**東**側鉤（座 x−284.5…−235）、`jhook_west` 是**西**側鉤（座 x−392…−342.5），`measureMinimumDistance = 0.0` 相接＝同一實體件。**bbox 包含關係 ≠ 幾何重疊。**
3. **`wo4_cup` 止付孔碎邊** — 縮孔後舊 ⌀3.6 孔壁殘留 4 個小面；重切成一根乾淨 ⌀2.8 圓柱穿過軌孔即消。

另記兩個工具坑：**Fusion STL 匯出會跳過隱藏 body**（`execute()` 仍回 True 但無檔案，`door_panel_flat` 中過）；**全時間軸重算（~790 特徵，3–5 分鐘）會把 base feature body 的改名還原**（`door_col_A`→`door_col_A_NEW`，發生兩次）。

## G. voice unit v1 — `vu1_panel`（9814.8 mm³ ≈ 12.2 g）

第一個 voice unit 的 DML 面板，**⌀3 C 形夾直接卡在骨架側軌**（x=±110 那條軛架直段，`door_col_A/R` 夾在同一條；門柱佔 z−72 以下，**z −20…−65 空著**）。
