## H. solo_min → unit1 LED 觸發驗證 PASS（下午，Harry「先試試 solo min 能不能觸發 LED」）

- **鏈路（首次全整合）**：喉麥 → AI-Micro in → `mulit-set` 聚集（2 in/4 out）→ solo_min 引擎 → **ch0/1＝AI-Micro 耳機孔 → unit1 音訊入** → ADC 分接 → 燈。啟動指令：`python app/solo_shell.py --in-name mulit-set --out-name mulit-set --out-map 0,1,0,1 --dry-ch 2`（S/T→ch0、A/B→ch1；乾聲丟 ch2＝不進 unit，**燈天生只看天使**，測試零污染）。
- **除錯梯（三層都踩過才通）**：①聲道順序——逐 ch 單放 440Hz 定位，**ch0/1＝unit（AI-Micro 在聚集前面）**，與「先猜 ch2/3」相反；②**AI-Micro 重插後輸入音量被重置**（聚集收到 peak 0.05＝gate 當靜音；系統設定拉滿後 0.44）——與 07-29 凌晨 Mac 麥 41→90 同型，**重插即重驗位準**應成反射；③輸出位準——0.7 測試音點燈但 converted 預設位準不夠，**CHOIR LEVEL 推到 +9 dB 有良好反應**。
- **設計行為確認**：燈敏銳度隨輸出位準線性走（envelope 跟振幅、MAX_LEVEL 0.30 封頂）＝CHOIR LEVEL 滑桿兼任燈敏感度旋鈕。engineering note：引擎只開 `max(out_map)+1` 聲道，**不給 --out-map 時 4ch 聚集的 ch2/3 是死的**；`--dry-ch` 超出 n_out 範圍＝乾聲靜默丟棄（本次刻意利用）。
- **待議**：+9 dB 是「無喇叭、純燈」的校準；exciter 接回來後聲學音量與燈敏感度會綁在同一根滑桿上，屆時要嘛韌體降 NOISE_FLOOR、要嘛分離增益。
